# 시각 자료 참고

Scratch 형태의 블록은 외부 서비스나 라이브러리 없이 로컬 SVG로 그립니다.
연결 홈, 이벤트의 둥근 윗부분, 카테고리별 색상, 숫자 입력칸은
[Scratch Foundation의 공식 블록 포스터](https://cms.scratchfoundation.org/assets/ae40e87e-f5b1-42bc-bfd3-32a65e418500)와
[Scratch Blocks](https://github.com/scratchfoundation/scratch-blocks)를 참고했습니다.

게임의 기존 《코딩맨》 모티프를 유지합니다. 원작의 그림이나 캐릭터 이미지를 새로 복제하지 않았습니다.
