# Codingman Remastered

만화 《코딩맨》에서 착안한 기존 코드 배틀 게임의 리마스터입니다.
2026-10-23 공통 로직 분리에 이어, 2026-10-24 창 크기 대응·원형 캐릭터·코드별 단축키·Scratch 형태의 블록을 적용했습니다.
원본 `../codingman`과 Idea 게임은 수정하지 않았습니다.

## 실행

`mainpage.html`을 열면 됩니다. 빌드나 게임 실행용 패키지 설치는 필요하지 않습니다.
웹사이트의 `../codingman.html`도 리마스터를 표시하며, 원본 링크를 따로 제공합니다.
Stage 5부터는 전투 전에 `code5.html?stage=5`에서 코드를 작성합니다. `stage` 값은 5~10입니다.
작성 후 **코드 실행** 또는 `Ctrl+Enter`를 누르면 저장된 프로그램으로 전투를 시작합니다.
전투 중 **코드 수정**으로 돌아갈 수 있습니다. 승리하면 다음 단계의 편집기로 이동합니다.
`stage5.html`이 기본 전투 페이지이며, `stage5.php`도 기존 주소 호환용으로 유지합니다. 게임 실행에는 PHP가 필요하지 않습니다.

## 사전 프로그래밍

편집기는 실제 실행되는 중첩 블록 프로그램을 만듭니다. 첫 방문에는 수정 가능한 예제가 들어 있습니다.
블록을 클릭하거나 단축키로 추가하고, 반복·조건 블록 내부의 **여기에 코드 추가**로 중첩 위치를 정합니다.
드래그 또는 ↑ ↓ 버튼으로 순서를 바꾸고, **한 단계 밖으로**로 상위 묶음으로 나갑니다.
입력값은 직접 편집할 수 있으며, 삭제·비우기·예제 교체는 **되돌리기**로 복원할 수 있습니다.

- Stage 5: 시작 / 키 입력 / 버그 동작 / 피격 이벤트, 반복 / 계속 반복 / 기다리기 / if / if-else / 조건까지 반복·대기 / 스크립트 정지
- Stage 6: 거리·체력 값, 버그의 가시성·접촉 조건과 감지 동작
- Stage 7: 숫자 비교, and / or / not, 값의 산술 연산
- Stage 8: 이름을 정한 변수의 설정·증가·참조와 에너지 충전
- Stage 9: 이름을 정한 리스트에 값 추가·삭제·초기화, 항목·길이 참조와 위치 경로
- Stage 10: 나만의 블록 정의·호출. 정의한 블록에서 다른 정의를 호출할 수 있습니다.

여러 이벤트는 함께 실행합니다. 같은 이벤트가 실행 중에 다시 발생하면 중복 실행을 쌓지 않습니다.
키 이벤트를 작성한 키는 기본 조작 대신 해당 프로그램을 실행하며, 다른 키와 마우스 조작은 병행할 수 있습니다.
코드와 직접 조작은 기술 대기 시간을 공유합니다. 대기 중인 기술 블록에서는 사용할 수 있을 때까지 기다립니다.
프로그래밍 단계의 조준은 즉시 실행되며 기본 공격 간격은 0.35초입니다. 숨기·크기 변경은 기존처럼 1초 효과입니다.

단계별 코드가 브라우저에 자동 저장되고, 새 단계의 첫 편집에서는 이전 단계의 코드를 이어받습니다.
변수·리스트는 전투마다 초기화되며, 재시작은 저장된 프로그램을 처음부터 실행합니다. 승패 시 코드와 전투 타이머를 모두 정리합니다.
잘못된 입력, 미해금 블록, 존재하지 않는 정의, 재귀 호출은 실행 전에 오류로 표시합니다. 빈 프로그램은 직접 조작으로 진행합니다.
프로그램은 256블록·24이벤트/정의·12단계 중첩, 리스트는 64항목까지입니다. 반복은 최대 1000회, 한 번의 기다리기는 최대 60초입니다.
프로그램을 JavaScript로 변환하거나 `eval`하지 않고 제한된 블록 실행기로 처리합니다. 빈 무한 반복도 화면을 멈추지 않습니다.

## 추가 챕터

새 챕터는 게임을 위해 만든 오리지널 전투이며, 감지 → 연산 → 변수 → 리스트 → 나만의 블록으로 이어집니다.
기존 이동·외형·소리 코드는 계속 사용할 수 있고, 새 코드도 이후 단계에 누적됩니다.

| 단계 | 새 기능 | 전투 |
| --- | --- | --- |
| 6 감지 | T: 2초간 버그의 위치와 거리 확인 | 은신 버그를 찾아 공격 |
| 7 연산 | G: 거리 ≤ 35이면 자동 조준하고 피해 2 발사 | 접근·후퇴하는 버그와 거리 조절 |
| 8 변수 | H: 에너지 +1, 최대 3 | 피해를 1 줄이는 장갑을 충전 공격으로 관통 |
| 9 리스트 | J: 위치 저장 / K: 순서대로 이동·조준·공격 | 복제 버그의 파동을 피하며 경로 활용 |
| 10 나만의 블록 | L: 감지 → 충전 3 → 조준 → 공격 → 후퇴 | 체력 18의 코어 버그, 절반 이하에서 부채꼴 공격 |

충전 에너지는 다음 기본 탄환에 모두 사용되어 피해가 1~4가 됩니다. 조건 공격은 고정 피해 2이며 에너지를 소비하지 않습니다.
경로는 3개까지 저장하며 초과하면 가장 오래된 위치를 교체합니다. 실행 시점에 저장된 경로를 0.45초 간격으로 방문합니다.
Stage 6 이후 기본 공격 간격은 0.35초입니다. 새 블록의 대기 시간은 감지 3초, 조건 공격 2.2초, 충전 1.2초, 경로 실행 5초, 콤보 8초입니다.
조건이 거짓이거나 빈 경로를 실행하면 대기 시간을 소모하지 않습니다. 최종 보스를 이기면 엔딩과 다시 플레이할 링크가 나옵니다.

## 조작

마우스로 블록을 클릭하거나 아래 키를 누르면 같은 코드가 실행됩니다.
창 크기에 따라 플레이 영역과 패널이 재배치됩니다. 작은 창에서는 코드를 스크롤할 때도 전투장이 보입니다.

| 키 | 코드 |
| --- | --- |
| ← / → | 좌우 회전 (연습 스테이지에서는 좌우 이동) |
| ↑ / ↓ | 전진 / 후진 |
| Space | 공격 |
| R / F | 무작위 이동 / 버그 바라보기 |
| W / S | 10걸음 / -10걸음 |
| B | 가장자리 확인 |
| Q / E | 왼쪽 / 오른쪽 45° 회전 |
| Z / X | 크기 줄이기 / 숨기 |
| C / V | 소리 / 음소거 |
| T / G | 감지 / 거리 조건 공격 |
| H | 에너지 충전 |
| J / K | 위치 저장 / 경로 실행 |
| L | debug combo |
| Enter | 승패 후 재시작 또는 다음 단계 |
| Esc | 메뉴 |

현재 스테이지에서 열린 코드만 사용할 수 있습니다.
블록의 키 표시와 실제 키 설정은 `js/commands.js`를 함께 사용합니다.
물리 키 위치를 사용하므로 한글 키보드 상태에서도 같은 위치의 키로 조작합니다.
숫자·문자 입력 중에는 게임 단축키가 실행되지 않습니다.
마우스와 키보드는 같은 재사용 대기 시간을 공유합니다.

편집기에서는 같은 키로 해당 블록을 추가합니다. `1/2/3`은 시작·버그·피격 이벤트, `P`는 키 이벤트,
`A/D/Y`는 반복·계속 반복·기다리기, `I/O/U/N`은 if·if-else·조건까지 반복·대기입니다.
`4/5`는 변수 설정·증가, `6/7/8`은 리스트 추가·삭제·비우기, `9/0`은 블록 정의·호출입니다.
각 블록에 단축키가 표시되며 `Delete`는 선택 블록 삭제, `Ctrl+Enter`는 작성한 코드로 전투 시작입니다.

## 구조

- `js/game.js`: 상태·이동·원형 크기·체력·승패·타이머 수명
- `js/effects.js`: 정사각형 전투장 좌표를 사용하는 발사체·파동·복제
- `js/stages.js`: 스테이지별 적 행동과 이벤트 반응
- `js/advanced-stages.js`: Stage 6~10의 감지·조건·에너지·경로·보스 패턴
- `js/stage-page.js`: 새 챕터의 공통 화면·미션 안내·누적 코드 팔레트
- `js/controls.js`: 키보드·마우스 공통 실행과 재사용 대기 시간
- `js/player-commands.js`: 수동 조작과 작성한 프로그램이 공유하는 동작·기술 대기 시간
- `js/program-model.js`: 블록 목록·프로그램 구조·단계별 검증·저장·이어받기
- `js/program-runtime.js`: 중첩 제어·이벤트·변수·리스트·정의 호출 실행기
- `js/program-battle.js`: 전투 전 준비·코드 실행·수정·실행 상태 표시
- `js/commands.js`: 공통 단축키·입력 보호
- `js/blocks.js`, `css/blocks.css`: 화면 크기에 맞춰 그리는 로컬 SVG 블록
- `js/block-assembler.js`: 중첩 블록 편집·입력·드롭·순서 변경·되돌리기
- `css/game.css`, `css/stage*.css`: 반응형 배치·정사각형 전투장·스테이지별 색상

캐릭터, 탄환, 파동은 모두 같은 정사각형 전투장 안의 0–100 좌표를 사용합니다.
창 크기를 변경해도 위치와 충돌 판정이 유지되고, 원이 타원으로 늘어나지 않습니다.
재시작 시 기존 타이머와 임시 효과를 정리하고 체력·쿨다운을 초기화합니다.
5단계의 미완성 PHP 루프는 제거했고, 모든 후속 단계가 편집 → 코드 실행 → 전투 → 다음 편집으로 이어집니다.

블록의 연결 홈·이벤트 모자·반복 C 모양·둥근 값 블록·육각 조건 블록·카테고리 색·둥근 입력칸은
[공식 Scratch 자료](SOURCES.md)를 참고했습니다. 외부 CDN이나 블록 라이브러리에 의존하지 않습니다.

## 검증

Node.js 22 이상, PHP, Microsoft Edge가 있는 환경에서 개발 의존성을 설치한 뒤 `npm test`를 실행합니다.
테스트가 로컬 서버(8766번 포트)와 테스트용 브라우저를 실행하고 종료합니다.

- 320×480, 390×844, 600×360, 800×600, 1280×720, 1920×1080에서 14개 페이지 검사
- 전투장·캐릭터의 정사각형 크기, 가로 넘침, SVG 블록과 키 표시 확인
- 모든 스테이지의 키보드·마우스 실행 결과 및 쿨다운 비교
- 진행 중 창 크기 변경과 서로 다른 창 크기의 충돌 판정 검사
- 승패·키보드 재시작·타이머 정리·메뉴 이동 검사
- 편집기의 중첩 조립·입력 보호·자동 저장·드롭·순서 변경·실제 전투 실행 검사
- 감지의 은신 해제·조건 경계값·에너지 상한과 소비·장갑·경로 순서·보스 페이즈 검사
- 실제 키 입력과 충돌 판정으로 Stage 6~10 클리어 후 엔딩 이동 검사
- 중첩 반복·대기·if-else·조건 대기·정지·동시 이벤트·피격 반응 검사
- 변수·리스트·정의 호출·공유 대기 시간·무입력 자동 승리·손상된 코드 처리 검사

화면 미리보기는 `tests/artifacts/`에 저장됩니다.
데스크톱·작은 창·사전 프로그래밍·추가 챕터 화면을 함께 검증합니다.
`CODINGMAN_TEST_FOCUS=programs`로 프로그래밍 실행 검증만 실행할 수 있습니다.
`CODINGMAN_TEST_URL`은 테스트할 리마스터 폴더 URL,
`CODINGMAN_TEST_BROWSER`는 Playwright 브라우저 채널을 지정합니다.
