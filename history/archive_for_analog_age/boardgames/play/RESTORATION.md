# 세계의 마블 웹판 복원 기록

이 웹판은 오찬솔의 보드게임 아카이브 사진을 바탕으로 만든 **검증 전 잠정 복원판**이다. 스케치북 16개, 종합장 8개를 플레이할 수 있다. 원본 JPEG와 기존 공개 제외 안내는 수정하지 않았다.

## 실행

`play/index.html`을 브라우저에서 열면 된다. 기존 웹사이트에서는 `/history/archive_for_analog_age/boardgames/play/`로 접근한다. 서버, 설치, 외부 라이브러리, 계정이 필요 없다. 진행은 같은 브라우저의 로컬 저장소에 저장된다. 파일을 직접 여는 브라우저의 저장 정책에 따라 저장이 제한될 수 있으며 화면에서 알린다.

맵을 고른 뒤 사람+컴퓨터 또는 한 기기에서 번갈아 하기를 선택한다. 인원 범위는 판의 표기를 우선한다. 기본은 20라운드이며 원본 승리 조건까지 무제한으로 할 수도 있다. 온라인 멀티플레이는 추가하지 않았다.

## 모든 주석을 확인하는 방법

웹 게임의 **복원 노트**에는 다음이 나온다.

1. 14장 설명서 원본과 보기 회전 기능.
2. 공통 복원 주석 R01–R24.
3. 맵별 보완 사항과 모든 칸의 전사 내용, 비용, 해석.
4. 전체 맵·모든 칸·주석 JSON 내려받기.

게임에서는 칸을 누르면 그 칸의 주석을 바로 볼 수 있다. 코드의 `data.js`는 `NOTES`, 맵의 `notes`, 칸의 `note`를 원본 대조 대장으로 사용한다. 주석이 없는 칸도 공통 보완 규칙을 적용한다. `engine.js`, `app.js`, `style.css`에도 실행 방식·표현 방식의 변경 주석을 남겼다.

## 중요한 해석과 한계

- **돈과 코인을 구분**했다. 돈은 건설·통행료에 사용하고 60,000코인은 대전 점수다. 주사위 재질별 자금/지폐 한도 표기는 해석이 불명확해 구현하지 않았다. 일반적인 초기 자금은 출발 보너스의 5배로 보완했고 설정에서 조정한다.
- 슬래시 금액은 건설비/통행료로 해석했다. 명시적으로 출입/구매가 구분된 종합장 월드맵은 해당 글씨를 우선했다. 건물 상세 가격표가 없는 일반 땅은 최대 2단계다. 2단계 건설비는 1단계와 같고 통행료는 2배다.
- 두 설명서의 코인 보상이 다르다. 「세계의 마블」의 파산 4,000 / 블랙홀 파산 3,500 / 블랙화이트홀 3,200 / 폭탄 3,000 / 라인 2,800 / 컬러 2,600 / 미사일 800 / 트리플 500 / 관광지 300을 기본 전사했다. 블랙홀 승리의 정확한 조건은 불명확해 발동하지 않는다.
- 작은 설명서의 별도 값은 파산 3,000 / 블랙화이트홀 파산 2,500 / 블랙화이트홀 폭탄 1,500 / 관광지 1,000 / 트리플 900 / 라인 1,200 / 미사일 750 / 폭탄 2,000으로 잠정 전사했다.
- 6면체 두 개와 균등 확률을 사용한다. 카드의 이름 10종은 남아 있지만 정확한 효과·매수·확률은 유실되어 보완했다. 실물 지폐와 은행 재고는 구현하지 않았다.
- 납부 부족 시 자산을 선택 매각한다. 자발적 파산도 가능하다. 무작위 수금과 반대 벌금은 상대 현금까지만 받도록 보완했다. 파산자의 소유지는 은행에, 공격 아이템은 회수한다.
- 원본의 공격 아이템도 플레이에 남겼다. ITEM에 가야 설치한다는 조건을 적용했다. 이름만 적힌 폭탄·미사일 등 지급 칸도 ITEM 지점으로 해석했다. 블랙홀은 전송으로 해석하고 화이트홀이 없으면 3회 휴식한다. 폭탄 1턴은 설치자의 다음 자기 차례 시작까지로 해석했다.
- 색·라인·관광지·트리플 독점의 세부 판정은 R10에서 정의했다. 북극/남극은 하트 4개 건설, 페스티벌+판타스틱은 지구 매입이라는 판의 조건을 공통 독점보다 우선한다.
- 비즈니스 4인은 교차 좌석끼리 팀을 맺고 팀장 2명이 가위바위보를 한다. 3·5인의 탈락 후 벌칙은 생존자들의 가위바위보로 정한다. 벌칙 장소는 다수결 인터페이스 대신 시작 전 직접 고르고, 벌칙 순간이동의 칸 효과는 다시 발동하지 않는다.
- 크로스맵은 원본 팔 배치를 유지하고 중앙에서 방향을 선택한다. 끝에서 반사되는 이동과 끝점 보너스는 보완이다. 크로스의 일반 독점 조건은 적용하지 않는다.
- BEST1은 나선 경주로 구현했다. 화살표도 칸으로 세는 것, 불명확한 안쪽 진행 순서, 챌린지4 실패 후 1회 휴식, 챌린지5의 임시 휴식, 처음 1천만원은 모두 보완이다. 이 판의 정확한 경로는 원작자 확인이 특히 필요하다.
- 마트맵/버이의 안쪽 연결은 브랜드 착지 순간이동, 랜드마크는 소유지 무료 증축으로 보완했다. 판 밖의 별도 랜드마크 체크 목표는 복원하지 못했다.
- 에브리웨어는 각자 다른 모서리에서 출발한다. 자기 출발점에서만 주회 보너스를 받는다.
- 다이아는 최대 2개씩, 각 5천만원이며 3개 이상 있어야 건설할 수 있다. 소모 여부가 없어 소비하지 않는 것으로 해석했다.
- 북극/남극의 팀전은 제안만 남아 있어 자유 개인전으로 구현했다. 눈보라의 최저 주사위 상대 결정은 무작위 상대 선택으로 보완했다.
- 종합장의 상하 분할 글씨는 별도 칸 대신 같은 칸의 제목/효과로 읽었다. 도형의 뜻이 없는 경우 일반 카드, 빈칸은 효과 없음으로 처리했다.
- 에브리띵은 로고만 남아 있어 경로 전체가 웹판 창작이다. 미완성 테마와 함께 중립 칸을 도는 5바퀴 경주 모드다. 미완성 비싸맵·퍼스트맵은 남아 있는 특수 칸·가격만 구현하고 빈칸을 새 도시로 채우지 않았다.
- 사진이 없는 신전 속은 기존 비공개 안내를 유지하고 복원하지 않았다.
- 웹판의 컴퓨터 전략, 자동 저장, 20라운드 기본 제한, 자산 평가 승리, 공동 우승, 화면의 말과 소유권 표시는 새로 추가한 기능이다. 자산은 현금+건설 정가 및 부가 자산의 1/4이다. 무료/할인 취득도 정가 기준 매각으로 해석했다.
- 안전하게 계속 진행할 수 있도록 연쇄 이동은 12회까지만 처리한다. 온라인 멀티플레이·외부 계정·결제는 포함하지 않는다.

## 파일 구성

- `index.html`, `style.css`, `app.js`: 정적 웹 화면.
- `data.js`: 원본 전사, 24개 맵, 591개 칸, 원본 파일 연결, R01–R24 주석.
- `engine.js`: 순수 게임 상태·규칙·저장 검사·컴퓨터 행동.
- `tests/engine.test.cjs`: 이동·돈·파산·아이템·독점·전체 맵 완료/재저장 회귀 검사.

규칙을 수정할 때는 `data.js`의 해당 값과 그 옆 주석을 함께 수정한다. 원작자의 확인이 이루어지면 ‘잠정’을 ‘확인’으로 바꾸고 근거를 기록한다.

검사: 저장소 루트에서 `node --test history/archive_for_analog_age/boardgames/play/tests/engine.test.cjs`.
